# Frontend Interview Prep

## JavaScript/TypeScript fundamentals
- Closures, prototypal inheritance, `this` binding, event loop/microtasks vs macrotasks, equality/coercion quirks, TypeScript's structural typing and generics.

## React/Next.js
- Reconciliation/virtual DOM, hooks rules and common pitfalls (stale closures, dependency arrays), Server vs Client Components, data fetching/caching strategies, when to use context vs a state library.

## Browser & performance
- Critical rendering path, reflow/repaint, the network waterfall, Core Web Vitals (LCP/CLS/INP), lazy loading/code splitting, memoization (`useMemo`/`useCallback`) — and when it's premature optimization.

## CSS & layout
- Box model, flexbox vs grid, specificity/cascade, responsive design approaches.

## Accessibility
- Semantic HTML, ARIA roles (and when *not* to add them), keyboard navigation, focus management in modals/SPAs.

## Sample question types
- "What happens between typing a URL and seeing the page", "why did this component re-render", "design a debounced search input", "fix this accessibility issue in this component".

## Practice format
- For coding questions, expect the candidate to build/modify a small component and explain trade-offs (state placement, re-render impact) as they go.
